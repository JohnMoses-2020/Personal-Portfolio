## Timeouts, retries, and budgets

Retries without limits turn a partial failure into a total one. A retry
budget caps how much extra load a failing dependency is allowed to generate.

```go title="retry.go"
// Sketch: allow at most 10% additional load from retries.
if retryBudget.Allow() {
    return attempt()
}
return ErrBudgetExhausted
```
